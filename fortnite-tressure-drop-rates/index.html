How you play

Each vault holds 3 Rare Chests (plus a Sprite Chest that doesn't count here), so each vault adds 3 chests to every game.
You open chests per game, or per hour. Pick a route on the map to fill this in.

Treasure Hour

What is Treasure Hour? A window when Epic raises the odds on the three rarest treasures. So far these run on Saturdays, reported as 2–4 PM ET and 9–11 PM ET. What does boost size mean? It multiplies the normal odds. A 2× boost turns Pirate Shop Access from 1 in 137,500 into 1 in 68,750 per chest. A 10× boost turns the Gold Outfit from 1 in 1,562,500 into 1 in 156,250. Other treasures never change.
Per Treasure Hour day. A Saturday has up to 4 boosted hours across both windows.

Pirate Shop Access: two weeks of free Item Shop

The token lets you claim any V-Bucks item in the shop for 14 days. Many items stay in the shop for several days, so the value is the shop on day one plus only the new items added on each of the next 13 daily resets.

Starting values: tracker PiTyUs counted 334 shop offers on Nov 8, 2026. We use 250 because bundles repeat items that are also sold one by one. Shop prices run from 300 to 2,000 V-Bucks, with most items under 1,000. Epic does not publish shop totals, so this is an estimate. Move the sliders if you track the shop yourself. Real-money offers and Battle Pass items can't be claimed and aren't counted.

Chest routes

What is a chest route? A landing plan: where to drop from the Battle Bus and which locations to loot in order, so you open as many chests as possible before the storm or other players stop you. What does picking one do? It draws the route on the map with numbered stops and sets Chests per game to what that route really gives. Not every spawn point has a chest each match, so that number is lower than the spawn count. Every odds card and the prize value then update to match.

Farming tips

  • Play public matches. Guides report the token does not drop in bot lobbies.
  • Save your best route for Treasure Hour. Every chest in that window rolls boosted odds for the token, Gold Outfit and vehicle.
  • Grab vault keys. Keys drop from chests. A vault adds 3 Rare Chests to your game in one stop.
  • Squad up. More players looting means more chests per match, and a token reportedly unlocks for the whole team.
  • Skip "token tracker" apps. No tool can see which chest holds a treasure.
