Farming tips

  • Play public matches. Guides report the token does not drop in bot lobbies.
  • Save your best route for Treasure Hour. Every chest in that window rolls boosted odds for the token, Gold Outfit and vehicle.
  • Squad up. More players looting means more chests per match, and a token reportedly unlocks for the whole team.
  • Zero Build helps. Less time building means more time moving between chests.
  • Skip "token tracker" apps. No tool can see which chest holds a treasure.
